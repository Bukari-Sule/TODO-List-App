# TODO List App

A simple TODO list built with HTML, JavaScript, and Tailwind CSS. It allows users to add, check off, and delete tasks — with tasks saved in the browser's local storage so they persist after reloading.



## Features

- Add and manage a list of tasks.
- Mark tasks as complete with a checkbox.
- Delete tasks with a click.
- Automatically saves to localStorage.
- Fully responsive with mobile support (thanks to Tailwind CSS).


## Technologies Used

- HTML5
- Tailwind CSS
- Vanilla JavaScript
- Local Storage API
